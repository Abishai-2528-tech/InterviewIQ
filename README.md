# InterviewIQ – AI-Powered Interview Preparation Platform

## Overview

InterviewIQ is an AI-powered career preparation platform designed to help students and job seekers improve their interview readiness through intelligent resume analysis, coding profile assessment, and personalized interview question generation.

The platform combines resume evaluation, profile analysis, and Large Language Models (LLMs) to provide actionable insights and tailored interview preparation experiences.

---

## Key Features

### Resume Analysis

* PDF resume parsing and extraction
* ATS-style evaluation
* Skill identification
* Missing skill detection
* Improvement recommendations

### Coding Profile Analysis

* GitHub profile assessment
* LeetCode profile analysis
* Coding activity evaluation
* Technical profile insights

### AI Interview Generation

* Personalized interview questions
* Domain-specific question generation
* Technical and behavioral interview preparation
* LLM-powered content generation

### Career Preparation

* Candidate profiling
* Skill gap identification
* Interview readiness insights
* Career growth recommendations
